* 手帳 Techō

Document storage API specifically geared for note taking.

#+begin_quote
✨ *AI Disclosure:* LLMs are used extensively in the planning and development of this project.
#+end_quote

** Status

Early. The server makes accounts and API keys, lets a person log in, and stores
notes with their history, in folders, which can be archived, trashed and
deleted. Links, tags, search and sync are not built yet.
[[file:.plans/outline.md][The outline]] says what is planned, and
[[file:.plans/progress.md][the ledger]] where it stands.

** Build and test

You need Linux, with Chez Scheme 10.4.1 or later (threaded), libuv 1.48 or
later, SQLite, libcurl, libsodium 1.0.18 or later, a C compiler and =pkg-config=. On a Guix host,
=scripts/guix-env= gives all of them, pinned.

The Makefile also runs on macOS, for development only: tested by hand, never in
CI. There, use Homebrew's SQLite and
libsodium, and name both before =make test=:

#+begin_src sh
brew install sqlite libsodium coreutils
export CHEZ_SQLITE3_LIBRARY="$(brew --prefix sqlite)/lib/libsqlite3.dylib"
export CHEZ_SODIUM_LIBRARY="$(brew --prefix libsodium)/lib/libsodium.dylib"
#+end_src

- Apple's own SQLite keeps the =-wal= file after the last close and answers locks
  differently: four suites fail on it and two hang.
- chez-sodium does not find libsodium by itself there.
- =brew --prefix= prints a path even when the formula is not installed. Check the
  file is there.
- =make test= needs =timeout=, or coreutils' =gtimeout=.
- Two tests that count threads in =/proc= are skipped, and a line says so.

#+begin_src sh
git clone https://github.com/Kiyomi-Computation-Systems/techo.git
cd techo
make submodules               # the six submodules under vendor/, each at its pin
make fetch                    # the Akku dependencies, as Akku.lock pins them
make test                     # builds chez-libuv's shim, then runs every tests/test-*.sps
#+end_src

On a Guix host the last line is =scripts/guix-env make test=. The
=make submodules= and =make fetch= lines stay on the host: they need git and the
network, which the container has not.

After a =git pull= that moves a submodule's pin, run =make submodules= again. Until
you do, =make deps= (and so =make test= and =make run=) stops and says which
submodule is behind.

=make help= lists every target.

** Run

#+begin_src sh
export TECHO_DB_PATH=/var/lib/techo/techo.db
make run ARGS=migrate                  # make the database
printf 'correct horse battery\n' | make run ARGS='user add --username ada --email ada@example.com'
make run ARGS=serve                    # in another terminal; leave it running
curl http://127.0.0.1:8080/health
curl -H 'Content-Type: application/json' \
  -d '{"email":"ada@example.com","password":"correct horse battery","name":"laptop"}' \
  http://127.0.0.1:8080/v1/login       # answers an API key, once
#+end_src

Send the key as =Authorization: Bearer KEY=. [[file:docs/api.md][The API]] has the
routes, and [[file:docs/running.md][Running Techo]] the settings.
